# MobGrinder

插件仓库地址：
```text
https://raw.githubusercontent.com/irimsky/DalamudPlugins/refs/heads/main/manifest.json
```

MobGrinder 是一个自动刷野怪的 Dalamud 插件。设置地图、目标野怪和完成条件后，插件会传送到目标地图，骑乘坐骑或飞行前往刷新点，寻找并接战目标。完成当前目标后继续其他目标。普通刷怪由外部战斗插件释放技能；驯兽师抓捕使用内置的攻击和捕获技能。

## 功能

- “驯兽师”页内置 40 种野外可抓捕魔兽，按图鉴编号抓捕所选魔兽，确认图鉴解锁后继续下一种。
- 按预设顺序安排多个地图和目标怪；寻找野怪时会同时检查当前预设中的所有未完成目标。
- 自动找以太之光并交给 Lifestream 传送。
- 使用 vnavmesh 骑乘坐骑跑图或飞行前往刷新点，接近目标后落地接战。
- 进入禁飞区后先落地，再使用地面导航；禁飞区有指定落点时先前往该落点，地面高度由 vnavmesh 解析。
- 接近野怪时，以开始导航那一刻的怪物位置为终点；到达接近范围后落地接战，怪物短距离移动不会改变本次终点。
- 落地卡住 6 秒时，会围绕固定的怪物位置依次尝试对称点、等腰直角三角形的直角点及其对称点；四个落点均失败后跳过当前怪物并继续巡回。
- 在刷新点等待并扫描附近目标，只要发现预设里的任意目标怪就会立刻过去接战；自动跳过危命任务野怪、友方、已被其他玩家占有的野怪和无法攻击的目标。
- 每个目标单独统计击杀数，支持按击杀数量或背包物品数量完成目标；已达到完成条件的目标会自动跳过。
- 支持刷完一轮后停下，或者从第一个目标继续循环。
- 窗口里可以看到当前状态、当前目标、刷新点、击杀数和运行日志；悬浮窗会显示本次目标列表、完成数量和每个目标的实时进度。

## 依赖

| 插件 | 用途 |
| --- | --- |
| **vnavmesh** | 骑乘坐骑跑图、飞行和路径查询 |
| **Lifestream** | 找以太之光传送和跨地图移动 |
| 战斗或职业循环插件 | 选目标、打怪和释放职业技能 |

普通刷怪请使用自己熟悉、能够处理当前职业和目标的战斗插件。驯兽师抓捕模式会自行释放技能，不需要 Wrath 自动循环。

## 快速开始

1. 在 Dalamud 的自定义插件仓库里添加上面的插件仓库地址。
2. 确认 vnavmesh、Lifestream 和战斗插件都已经加载。
3. 输入 `/mobgrinder` 或 `/mg` 打开窗口。
4. 在“预设”里添加野怪，选择地图和目标，设置击杀数量或背包物品数量等完成条件。
5. 点击“设置”按钮或标题栏齿轮，在独立设置窗口里打开“显示悬浮窗”，或调整移动与导航、音效。刷新点飞行高度默认为 15 码。
6. 在“预设”的“一轮结束后”勾选“停止刷怪”或“继续循环”，然后到“运行”页点击“开始刷怪”。
7. 第一次运行或改完配置后，建议先在熟悉的地图观察传送、上坐骑、落地、接战和脱战是否正常。

## 命令

命令前缀支持 `/mobgrinder` 和简写 `/mg`。

| 命令 | 作用 |
| --- | --- |
| `/mobgrinder`、`/mobgrinder ui` | 打开主窗口 |
| `/mg config` | 打开设置窗口 |
| `/mg start` | 开始或继续刷怪 |
| `/mg pause` | 暂停刷怪并停下当前导航 |
| `/mg stop` | 停止刷怪 |
| `/mg scan` | 刷新周边野怪列表 |
| `/mg status` | 在日志里输出当前状态 |
| `/mg log` | 打开运行日志 |

## 预设、刷怪数量和循环

### 预设

一个预设可以放多个地图和目标怪。插件会按列表顺序执行，当前目标完成后，继续下一个地图或目标。

在当前地图发现预设中的任意未完成目标时，插件都会优先接战，并分别统计击杀数量。列表顺序用于安排跨地图传送和刷新点巡回。

删除预设时，先点击“删除预设”，核对预设名称后再次点击“确认删除”。可以点击“取消删除”撤销确认；切换预设、切换页面或关闭窗口也会取消确认。至少保留一个预设，运行期间不能删除预设。

### 完成条件

每个目标可以设置：

- 击杀数量达到设定值；
- 背包中的指定物品数量达到设定值。

同一个目标勾选多个条件时，需要全部满足才算完成。未设置完成条件的目标会持续刷怪，直到手动暂停或停止。开始时已达到全部条件的目标会标记为完成并跳过。

### 一轮结束后

两个勾选项互斥，始终选择其中一项，仅适用于普通刷怪：

- **停止刷怪**：当前预设的所有目标完成后停止；
- **继续循环**：所有目标完成后，重新开始下一轮。

## 驯兽师抓捕

1. 切换到驯兽师，打开插件的“驯兽师”页，勾选需要抓捕的魔兽。
2. 设置“捕获血量”（0–100%，默认 30%）。
3. 点击独立的“开始抓捕”按钮。插件先检查图鉴并跳过已解锁魔兽，按图鉴编号执行；全部解锁后停止。普通“开始刷怪”仍使用正常预设，抓捕不会改动普通预设。

“测试抓捕”按钮用于先验证战斗流程：每种所选魔兽必须先接战并击败一只，再读取图鉴状态。启动和首次战斗前不等待图鉴数据，也不因已经解锁而跳过目标。战后已解锁就换下一项，未解锁则继续抓同一种；后续魔兽也先击败一只。暂停后用对应的“继续抓捕”或“继续测试抓捕”按钮恢复。

普通刷怪、抓捕和测试抓捕互斥，暂停时也不能切换；切换前先停止当前流程。各页面只控制自己的流程，悬浮窗控制当前流程。`/mg start` 只开始或继续普通刷怪，IPC 单目标只在所有流程停止后接受启动。

插件会使用 1 级技能“碎击斩”降低目标血量，HP 小于或等于阈值时优先释放“捕获”，然后循环“碎击斩 → 碎咬斧 → 裂盾劈”直到击败目标。清理非目标野怪时也使用这套连招。碎咬斧为 2 级技能，裂盾劈为 12 级技能；后续技能尚未学会或因等级同步无法使用时，回到碎击斩重新开始。技能冷却或暂时释放失败时等待重试，连招以游戏实际连击状态为准；切换目标或进入连招阶段时从碎击斩开始。捕获会给野怪施加标记，**击败带标记的目标后才判定是否加入图鉴**；因此释放技能或击杀本身都不算完成，必须读取到实际图鉴解锁才会换下一种。没有解锁会继续抓同一种。

目标等级低于 10，或比角色当前有效等级低至少 10 级时，开场先捕获一次；之后到达阈值时可再捕获一次。开场捕获时若 HP 仍高于阈值，继续只用碎击斩降低目标血量；到阈值并释放捕获后才切换连招。0% 不触发常规血量捕获，但仍保留低等级开场捕获。技能未就绪时会暂缓攻击技能和自动攻击，优先等待捕获，成功发出后再继续攻击。高于角色有效等级的目标无法捕获，当前条目的最低等级过高时会停下并提示。

页面显示图鉴编号、魔兽和目标野怪名称、地图、等级、图鉴状态及刷新点数量；将鼠标停留在刷新点数量上可查看部分坐标。资料来自[艾欧泽亚天气](https://eorzea-weather.com/zh/beastmaster)，来源和全部网站坐标见[驯兽师来源记录](docs/beastmaster-sources.md)。包括普通野外 B 级狩猎怪；任务、副本和 FATE 专属来源不加入此列表。正常抓捕在开始前等待图鉴数据，测试抓捕在击败目标后才等待；30 秒仍未就绪则停止。出现等待提示时，在游戏中打开一次魔兽图鉴以加载解锁状态，再重新开始。目标消失或尚未接战就死亡，不算完成测试的首次战斗。

抓捕选择在一次运行内固定；暂停、停止、登出、切换职业、依赖失效和卸载都会停止插件发技能与导航。切地图时先停止导航，区域稳定后再继续。角色自身死亡时抓捕停止。当前实现尚未进行游戏内验证。

## 注意事项

- 这是一个会自动传送、跑图、接战和刷怪的插件，第一次使用请先观察完整流程。
- 请确认角色已经解锁目标地图的以太之光，并有可用的传送、坐骑和飞行条件。
- vnavmesh 或 Lifestream 未加载或运行期间不可用时，相关任务会停止。请检查窗口中的依赖状态和 `/mg log` 运行日志。
- 普通模式不负责战斗技能。没有合适的战斗插件时，角色可能到达目标附近却无法正常战斗。驯兽师抓捕使用内置攻击和捕获技能。
- 插件使用的刷新点资料可能遗漏部分位置；需要时可以按 Wiki 数据手动补充到 `MobGrinder/Data/MobSpawnSupplementData.cs` 的 `MobSpawnSupplementData.Entries` 集合。目前已录入 7.0 幻武所需野怪，以及九本黄道文书中符合补充条件的位置；完整数量与坐标对照见[黄道文书野怪坐标核对](docs/zodiac-book-spawns.md)。
- 游戏更新后如果出现传送、跑图、落地或找怪异常，可以先查看 `/mg log`，再确认 Dalamud、vnavmesh 和 Lifestream 是否正常。
