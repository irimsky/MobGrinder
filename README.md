# MobGrinder

Repo install URL:
```text
https://raw.githubusercontent.com/irimsky/DalamudPlugins/refs/heads/main/manifest.json
```

MobGrinder 是一个用来自动刷野怪的 Dalamud 插件。你在预设里配好地图和目标怪之后，插件会找以太之光传送、骑鸟跑图或飞行到刷怪点，等怪、接战，刷够数量后换下一个目标。战斗技能交给其他战斗插件处理。

## 功能

- 按预设顺序安排多个地图和目标怪；巡回时会同时盯着本次预设里的所有未完成目标。
- 自动找以太之光并交给 Lifestream 传送。
- 使用 vnavmesh 骑鸟跑图或飞行前往刷怪点，接近目标后落地接战。
- 在刷怪点等待并扫描附近目标，只要发现预设里的任意目标怪就会立刻过去接战；自动跳过 FATE、友方、别人正在打的怪和不能攻击的目标。
- 每个目标单独统计击杀数，支持按击杀数量或背包物品数量结束目标；已满足停止条件的目标会自动跳过。
- 支持刷完一轮后停下，或者从第一个目标继续循环。
- 窗口里可以看到当前状态、当前目标、刷怪点、击杀数和诊断日志；悬浮窗会显示本次目标列表、完成数量和每个目标的实时进度。

## 依赖

| 插件 | 用途 |
| --- | --- |
| **vnavmesh** | 骑鸟跑图、飞行和路径查询 |
| **Lifestream** | 找以太之光传送和跨地图移动 |
| 战斗或职业循环插件 | 选目标、打怪和释放职业技能 |

战斗插件请使用自己熟悉、能够处理当前职业和目标的插件。MobGrinder 只负责传送、跑图、找怪和流程控制，不会自己打技能。

## 快速开始

1. 在 Dalamud 的自定义插件仓库里添加上面的 Repo install URL。
2. 确认 vnavmesh、Lifestream 和战斗插件都已经加载。
3. 输入 `/mobgrinder` 或 `/mg` 打开窗口。
4. 在“预设”里添加目标，选好地图、目标怪和刷够多少停。
5. 想边刷边看进度的话，在“设置”里打开“显示悬浮窗”。
6. 在“运行”里选择刷完一轮后停下还是继续循环，然后点“开始刷怪”。
7. 第一次运行或改完配置后，建议先在熟悉的地图观察传送、骑鸟、落地、接战和脱战是否正常。

## 命令

命令前缀支持 `/mobgrinder` 和简写 `/mg`。

| 命令 | 作用 |
| --- | --- |
| `/mobgrinder`、`/mobgrinder ui`、`/mobgrinder config` | 打开主窗口 |
| `/mg start` | 开始或继续刷怪 |
| `/mg pause` | 暂停刷怪并停下当前导航 |
| `/mg stop` | 停止刷怪 |
| `/mg scan` | 立刻扫一遍附近目标 |
| `/mg status` | 在日志里输出当前状态 |
| `/mg log` | 打开诊断日志 |

## 预设、刷怪数量和循环

### 预设

一个预设可以放多个地图和目标怪。插件会按列表顺序执行，当前目标刷够后换下一个地图或目标。

实际扫描时不会只盯着列表当前这一项：只要当前地图出现预设里任何一个尚未完成的目标怪，都会优先过去接战。列表顺序主要用来安排传送和刷怪点巡回；每一项的击杀数仍然单独记录。

### 停止条件

每个目标可以设置：

- 击杀多少只后结束；
- 背包里的指定物品达到多少后结束。

同一个目标勾选多个条件时，需要全部满足才算完成。没有设置停止条件的目标会一直刷，直到你手动暂停或停止；如果某项在开始时物品数量已经够了，也会直接标成完成并跳过。

### 运行模式

- **一轮结束后停止**：当前预设全部刷完后停下；
- **一轮结束后继续循环**：当前预设刷完后回到第一个目标继续刷。

## 注意事项

- 这是一个会自动传送、跑图、接战和刷怪的插件，第一次使用请先观察完整流程。
- 请确认角色已经解锁目标地图的以太之光，并有可用的传送、坐骑和飞行条件。
- vnavmesh 或 Lifestream 挂了、没加载或中途失效时，相关流程会停下；先看窗口里的依赖状态和 `/mg log`。
- MobGrinder 不负责战斗技能。没有合适的战斗插件时，角色可能找到怪但不会正常输出。
- 因不明原因，部分野怪的刷怪点在客户端数据里可能是空的；需要时可以按 Wiki 数据手动补充到 `MobGrinder/Data/MobSpawnSupplementData.cs` 的 `MobSpawnSupplementData.Entries` 集合。目前这里已经录入 7.0 幻武所需野怪的刷怪点。
- 游戏更新后如果出现传送、跑图、落地或找怪异常，可以先查看 `/mg log`，再确认 Dalamud、vnavmesh 和 Lifestream 是否正常。
