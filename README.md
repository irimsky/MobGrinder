# MobGrinder

Repo install URL:
```text
https://raw.githubusercontent.com/irimsky/DalamudPlugins/refs/heads/main/manifest.json
```

MobGrinder 是一个面向《最终幻想 XIV》的 Dalamud 自动化插件，用于按预设传送到目标地图、前往野怪静态刷新点、扫描目标并循环处理。插件负责流程控制、移动和目标管理，不负责施放战斗技能。请同时运行能够处理当前目标的战斗或职业循环插件。

## 功能

- 按预设顺序循环处理多个地图和野怪目标。
- 自动通过 Lifestream 传送到目标地图。
- 使用 vnavmesh 飞行或地面导航前往静态刷新点。
- 在刷新点等待并扫描符合条件的野怪目标。
- 过滤 FATE 目标、友方目标、他人战斗归属和不可攻击目标。
- 支持按击杀数量或背包物品数量停止当前野怪项目。
- 支持一轮预设完成后停止，或继续循环执行。
- 提供运行状态、依赖状态、扫描结果和诊断日志。

## 依赖

| 插件 | 用途 |
| --- | --- |
| **vnavmesh** | 地面导航、飞行导航和路径查询 |
| **Lifestream** | 目标地图传送和区域移动 |
| 战斗或职业循环插件 | 处理目标、建立仇恨和施放实际战斗技能 |

战斗相关需要运行能够处理当前职业和目标的战斗插件。MobGrinder 不替代战斗插件，也不会自行选择或施放职业技能。

## 快速开始

1. 在 Dalamud 的自定义插件仓库中添加上方的 Repo install URL。
2. 确认 vnavmesh、Lifestream 和战斗插件均已加载并正常运行。
3. 使用 `/mobgrinder` 或 `/mg` 打开主窗口。
4. 在“预设”中创建目标，选择地图、野怪和停止条件。
5. 在“运行”中选择一轮完成后的运行模式，点击“开始刷怪”。
6. 首次使用或修改配置后，先在低风险场景观察传送、导航、落地、目标选择和战斗插件行为。

## 命令

命令前缀支持 `/mobgrinder` 和简写 `/mg`。

| 命令 | 作用 |
| --- | --- |
| `/mobgrinder`、`/mobgrinder ui`、`/mobgrinder config` | 打开主窗口 |
| `/mg start` | 开始或继续自动刷怪 |
| `/mg pause` | 暂停自动化并停止当前导航 |
| `/mg stop` | 停止自动化 |
| `/mg scan` | 立即执行一次扫描 |
| `/mg status` | 输出当前运行状态 |
| `/mg log` | 打开诊断日志 |

## 预设和停止条件

### 预设

一个预设可以包含多个地图和野怪项目。插件会按预设顺序执行每个项目，项目完成后前往下一个刷新点或下一个野怪项目。

### 停止条件

每个野怪项目可以配置以下条件：

- 击杀数量达到指定值；
- 背包中指定物品达到指定数量。

同一个项目勾选多个条件时，所有条件都满足后才会进入下一个项目。

### 运行模式

- **一轮结束后停止**：当前预设中的所有项目完成后停止自动化；
- **一轮结束后继续循环**：完成当前预设后从第一个项目重新开始。

## 注意事项

- 这是一个会自动传送、移动并参与战斗的插件。首次使用时请观察完整流程。
- 请确保角色已经解锁目标地图的传送入口，并拥有可用的传送、坐骑和飞行条件。
- vnavmesh 或 Lifestream 不可用时，相关流程会暂停或停止；请先确认依赖状态正常。
- MobGrinder 只负责目标和流程控制，实际战斗行为完全依赖外部战斗插件。
- 游戏更新可能改变 Dalamud、IPC、对象识别或导航行为；遇到异常时请先查看 `/mg log` 的诊断信息。
- 因不明原因，部分野怪的静态刷新点在客户端数据中可能为空；如有需要，可根据 Wiki 数据手动补充到 `MobGrinder/Data/MobSpawnSupplementData.cs` 的 `MobSpawnSupplementData.Entries` 集合中。目前该集合已录入 7.0 幻武所需野怪的刷新点。
