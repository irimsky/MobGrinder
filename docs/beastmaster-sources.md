# 驯兽师野外来源记录

采集日期：2026-10-05。数据来源：[艾欧泽亚天气：驯兽师](https://eorzea-weather.com/zh/beastmaster)；网页资源 `BeastmasterView-B6aEdZu3.js`。

网站共有 50 条图鉴。普通野外来源共 40 种，包括粘液怪的阴沟毒液、灯心蜻蛉的君王鬼蜻蜓、祖的角祖等 B 级狩猎怪。仅有任务、副本或 FATE 来源的 No.01、18、37、38、43、45、47、48、49、50 不纳入自动抓捕。

硬编码入口为 `MobGrinder/Data/BeastmasterCatalog.cs`。完整来源、中文名称、图鉴编号、BNpcNameId、TerritoryTypeId、等级和网站坐标见同目录 `beastmaster-sources.json`，运行时不联网、不读取此 JSON。网站点位和生息范围圆心共 596 个；圆心是大致巡回位置，原始半径保留在源码和 JSON 中。阴沟毒液与角祖没有网站坐标，使用插件已依赖的 LuminaSupplemental.Excel 5.1.2 内嵌 MobSpawn.csv。运行时合并已有坐标，并按世界 X/Z 去重；导航高度由 vnavmesh 地面查询决定。网站的死魂名称对应多个 BNpcNameId，全部保留，同地图内按 NameId 匹配。

职业与技能已核对本机中文游戏表，并用 XIVAPI 英文表核对：BST = ClassJob 43，碎击斩（Smash Axe）= Action 44879、1 级；捕获（Capture）= Action 44880、1 级、距离 10、复唱 2.5 秒。参考：[职业表](https://v2.xivapi.com/api/sheet/ClassJob/43?fields=Name,Abbreviation)、[碎击斩](https://v2.xivapi.com/api/sheet/Action/44879?fields=Name,ClassJobLevel)、[捕获](https://v2.xivapi.com/api/sheet/Action/44880?fields=Name,ClassJobLevel,Range,Recast100ms)、[捕获说明](https://v2.xivapi.com/api/sheet/ActionTransient/44880?fields=Description)。捕获施加 120 秒的标记，击败带标记的野怪后才判定图鉴解锁；成功率受释放时的 HP 和等级差影响，对高于自己的目标无效。

连招技能同样核对中文游戏表与 XIVAPI：[碎咬斧（Axeblade Bite）](https://v2.xivapi.com/api/sheet/Action/44883?fields=Name,ClassJobLevel,ClassJob,ActionCombo,UnlockLink) = Action 44883、2 级、前置碎击斩；[裂盾劈（Shieldsplitter）](https://v2.xivapi.com/api/sheet/Action/44885?fields=Name,ClassJobLevel,ClassJob,ActionCombo,UnlockLink) = Action 44885、12 级、前置碎咬斧。达到血量阈值并成功发出捕获请求后，或清理非目标野怪时，循环碎击斩 → 碎咬斧 → 裂盾劈；开场捕获时 HP 高于阈值则仍只用碎击斩。后续技能未学会时回到碎击斩；学习判断同时检查有效等级及 `IUnlockState.IsActionUnlocked`，技能冷却/请求失败不视为未学会。读取 `ActionManager.Combo.Action/Timer` 的值快照推进连招，切换目标或进入连招阶段时从碎击斩重新开始。

[XBMPet 表](https://v2.xivapi.com/api/sheet/XBMPet?limit=100&fields=Pet.Name)逐条核对了图鉴编号与 Pet RowId 的对应关系（01–50）。解锁读取使用当前 Dalamud 的 `IUnlockState.IsXBMPetListLoaded` 和 `IsXBMPetUnlocked(XBMPet)`，源码内部通过 `XBMManager` 读取服务器同步的数据。插件不以击杀次数、捕获技能调用成功或本地手动标记替代真实解锁；正常抓捕的未同步状态为未知，暂停抓捕并提示打开图鉴。“测试抓捕”逐个项目先击败一只，首次战斗前不读取或等待图鉴状态；确认接战目标死亡且清理仇恨后，强制获取战后图鉴快照，再判定是否完成。已解锁项目仍须经过自己的首次测试战斗。单纯目标消失不算击败。所有读取和技能调用在 Framework 线程，UI 只读取复制值和发送控制器请求。
